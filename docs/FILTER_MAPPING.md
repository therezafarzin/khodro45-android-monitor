# نگاشت فیلترها

| رابط | پارامتر URL | وضعیت |
|---|---|---|
| حداکثر قیمت | `price__lte` | از URL کاربر بدون تغییر منطقی وارد می‌شود |
| حداقل قیمت | `price__gte` | از URL کاربر بدون تغییر منطقی وارد می‌شود |
| ترتیب | `ordering` | از URL کاربر وارد/صادر می‌شود |

مقادیر برند، مدل، تریم، سال و وضعیت باید پس از کشف endpoint متادیتای واقعی در همان فایل و در `Khodro45Client` ثبت شوند. این احتیاط مانع از ارسال پارامتر ساختگی به سرویس می‌شود.
