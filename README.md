# Khodro45 Monitor

Native Android application for monitoring listings on a user's authorized Khodro45 account. It does not make purchases, offers, or payments.

## Stack

- Kotlin
- Jetpack Compose
- Gradle / Android SDK
- Room

## Build

```bash
./gradlew test lint assembleDebug
```

The debug APK is produced under `app/build/outputs/apk/debug/` and is intentionally not tracked by Git.

## Security

Keep authentication, cookies, tokens, private signing keys, `keystore.properties`, and generated APKs on the local machine. Do not commit them.
