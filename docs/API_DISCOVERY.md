# API discovery — Khodro45

در تاریخ ۲۰۲۶-۱۰-۰۴ صفحهٔ عمومی `https://dealer.khodro45.com/cars` با HTTP 200 دریافت شد و مشخص شد SPA عمومی bundle `assets/index-vIqAMPvj.js` را بار می‌کند. دریافت مستقیم همان bundle از محیط build با HTTP 502 ناموفق بود؛ بنابراین هیچ endpoint حدسی به‌عنوان API تولیدی در کد ثبت نشده است.

برنامه فقط با نشست قانونی خود کاربر طراحی شده است و CAPTCHA، کنترل دسترسی یا سازوکار ضدبات را دور نمی‌زند. مسیر تولیدی تأییدشده `https://khodro45.com/api/v1/auctions/` است و با `Authorization: Token` مشتق‌شده در لحظه از نشست WebView فراخوانی می‌شود؛ توکن هرگز ذخیره یا گزارش نمی‌شود. Diagnostics فقط برای گزارش فنیِ redacted است و مسیر تولیدی را تغییر نمی‌دهد.

نمونه‌های قدیمیِ مستندشده (`price__lte`، `ordering` و فیلدهایی مانند `last_price`) فقط برای سازگاری در parser به‌صورت اختیاری پشتیبانی شده‌اند؛ معتبر بودن فعلی آن‌ها تأیید نشده است.
